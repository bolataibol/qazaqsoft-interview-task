# Qazaqsoft Interview Quiz  
Простое веб-приложение викторина, созданное как тестовое задание для отбора на стажировку.  

## Что внутри  
- Вопросы и варианты ответов отображаются на HTML-странице.  
- В первом вопросе пришлось изменить запись вариантов:  
  - Изначально ответы содержали `<h1>`, `<title>` и другие теги.  
  - Браузер воспринимал их как настоящие HTML-теги и не показывал текст.  
  - Решение: заменил `<` и `>` на `&lt;` и `&gt;`, чтобы ответы отображались правильно.  

## Использованные технологии  
- HTML  
- CSS  
- JavaScript  

## Использование искусственного интеллекта  
Использовал ИИ в выполнении задания, а именно chat-GPT и Grok.
